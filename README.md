# Offline Hindi Voice Assistant

## Overview

An offline, privacy-preserving Hindi voice assistant designed for Raspberry Pi.

The system processes Hindi voice commands locally without sending data to cloud services.

## Features

* Offline speech recognition
* Hindi text-to-speech
* Low-latency processing
* Privacy-preserving operation
* Raspberry Pi deployment
* Wake-word support (planned)

## Hardware Requirements

* Raspberry Pi 5
* USB Microphone
* Speaker
* MicroSD Card

## Software Stack

* Python
* Vosk ASR
* Piper TTS
* Raspberry Pi OS

## System Architecture

Microphone
→ Speech Recognition (ASR)
→ Intent Engine
→ Response Generator
→ Text-to-Speech (TTS)
→ Speaker

## Project Status

Planning and architecture design phase.
